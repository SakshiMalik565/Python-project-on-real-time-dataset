This repository contains an exploratory data analysis project focused on the Certified Public Accountants (CPAs) dataset from Washington State. The analysis explores license status, demographics, expiration trends, professional development, and regulatory compliance using Python and data visualization libraries.

📁 Dataset
Filename: Washington_State_Certified_Public_Accountants_20250306.csv

Source: [Washington State Public Records] (Manually downloaded)

Contains: Information about CPAs including license status, city, country, issue/expiration dates, etc.

📈 Key Visualizations
->Bar charts of license status distribution

->Pie charts for top cities by CPA count

->Histograms for expiration years and license durations

->Boxplots and scatterplots for duration trends

->Line charts to show regulatory trends over time
